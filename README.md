# 📚 تحليل بيانات المكتبة باستخدام Power BI - Library Data Analysis


تقرير تفاعلي تم تصميمه باستخدام برنامج **Power BI Desktop** لتحليل بيانات الإعارة الخاصة بالمكتبة (`Library_Books.xlsx`). يركز المشروع على استخراج رؤى دقيقة وتطبيق تقنيات التصفية المتقدمة (**Top N Filtering**).

### 🔍 الأهداف والنتائج:
* **أفضل 5 كتب إعارة:** تم استخدام فلتر `Top 5` لتحديد الكتب الأكثر طلباً، وتصدرها كتاب "الذكاء الاصطناعي" بواقع 25 إعارة.
* **أفضل 3 تصنيفات:** استخراج وتصنيف القطاعات الأكثر نشاطاً، وحل بالمرتبة الأولى قطاع "تقنية" بـ 104 إعارات.
* **أقل 3 كتب إعارة:** استخدام فلتر `Bottom 3` لتحديد الكتب الأقل طلباً لدعم خطط اقتناء الكتب المستقبلية.
* **التصميم والواجهة:** تم تطبيق نسق لوني متناسق (درجات البني) مع حواف منحنية (Rounded Corners) لضمان تجربة مستخدم UI/UX احترافية.

---

 English Description
An interactive dashboard built with **Power BI Desktop** to analyze library loan data (`Library_Books.xlsx`). The project focuses on extracting accurate insights and implementing advanced **Top N Filtering** techniques.

### 🎯 Objectives & Key Insights:
* **Top 5 Books:** Applied `Top 5` filtering to highlight the most frequently borrowed books, led by "Artificial Intelligence" with 25 loans.
* **Top 3 Categories:** Identified the most active categories, with "Technology" ranking first with 104 loans.
* **Bottom 3 Books:** Used `Bottom 3` filtering to pinpoint the least borrowed books for future collection management.
* **Design & UI:** Styled with a cohesive brown color scheme and rounded cards for a clean, professional user interface.
